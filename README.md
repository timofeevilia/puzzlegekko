# Golden Land

Настольная игра в духе «Монополии» для двоих, перенесённая в Таиланд и Мьянму. Интерфейс на английском.

Весь код игры находится в одном файле `index.html`: разметка, стили, данные поля и логика. Сборка и зависимости не нужны.

## Как играть

- **Онлайн, каждый со своего телефона.** Работает в версии игры на claude.ai: ходы, кубики и реакции синхронизируются через общую базу данных страницы. Партнёра нужно пригласить через Share по email с правом **Editor**. Публичную ссылку при этом не включайте.
- **На одном устройстве.** Откройте `index.html` в браузере или выложите его на GitHub Pages. Без claude.ai игра идёт только в режиме «оба на одном экране», а сохранённая партия хранится в браузере.

## Что есть в игре

- **Поле.** 22 реальных места, по 11 в Таиланде и Мьянме, с названиями тайским и бирманским письмом. Вместо железных дорог транспорт (Yangon Circular Train, BTS, Gokteik Viaduct, речной катер), вместо коммунальных предприятий Thanaka Works и Tuk-Tuk Co.
- **Углы.** Mingalaba! (старт), Visa Run (тюрьма), Water Festival (копилка налогов) и Overstay! (отправка в тюрьму).
- **Панель справа** (на телефоне под полем). Там всё, что можно сделать в свой ход, по вкладкам:
  - **Build** — постройка хижин и курортов. Клетки, где можно строить, подсвечиваются на поле.
  - **Deals** — обмен и **выкуп**: участок партнёра можно забрать принудительно за 2× цены, если у вас уже есть часть этого набора. Один выкуп за ход. Набор, где стоят постройки, защищён.
  - **Bank** — кредит до ฿500 плюс половина стоимости ваших участков; 10% процентов при каждом проходе старта. Здесь же залог участков.
  - **Market** — индекс SET, рубины Могока и золото. Цены меняются после каждого хода и от новостей; SET платит дивиденды.
- **Сезоны.** Аренда растёт: ×1.25 с 7-го круга, ×1.5 с 13-го, ×2 с 19-го.
- **Мини-игры** каждые 5–8 ходов: угадать место по надписи, удары по мячу чинлон, рубиновая шахта.
- **Карты.** Fortune Sticks и Merit Box. Language moments: научить партнёра слову; если получилось, оба получают ฿50.

## Проверка

```
node tests/simulate.js
```

Скрипт прогоняет 200 случайных партий через правила из `index.html`. Он падает, если игра застревает или деньги и цены становятся некорректными.
