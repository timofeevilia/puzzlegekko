# PuzzleGekko

Небольшие игры для двоих, которые говорят на разных языках. Сайт: https://timofeevilia.github.io/puzzlegekko/

| Папка | Игра | Как играть |
|---|---|---|
| `golden-land/` | **Golden Land** — игра в духе «Монополии» по Таиланду и Мьянме | онлайн, каждый со своего телефона (через Firebase), или вдвоём на одном устройстве |
| `tolmach/` | **Толмач · စကားပြန်** — игра на слух для русского и бирманского | онлайн, каждый со своего телефона (видит только свою половину), или на одном экране |
| `party/` | **Gekko Party** — набор игр для компании: «Последний поезд» (викторина со смертельными испытаниями), «Каракули и враки» (рисуй и блефуй), «Быстрый карандаш» (рисунок вживую, угадывают на скорость), «Копия копии» (перерисовка по памяти по цепочке), «Примерно» (угадай число и сделай ставку) | один большой экран (ТВ, ноутбук) + телефоны всех игроков; версии «Для двоих» (RU + MY), «English» и «Русский» |
| `journey/` | **81 Trials / 81 испытание** (西游记): головоломки по «Путешествию на Запад» | один игрок; русский и английский; открыто 6 из 81 испытания |
| `equilibrium/` | **Equilibrium / Равновесие**: игра на доверие и предательство для одного игрока | один игрок против пяти ИИ; русский и английский |
| `merit/` | **Merit Academy** (архив): кампания из четырёх экзаменов | только ссылка в подвале главной |
| `sabai-thai/` | **Sabai Thai · ထိုင်းစကား** — курс тайского для бирманоговорящих | вход через Google или по коду обучения; прогресс сохраняется в Firebase |

Устройство репозитория:
- `index.html` — главная страница со списком игр.
- `shared/net.js` — онлайн-комнаты на Firebase. Используется анонимный вход и Firestore.
- `shared/firebase-config.js` — конфиг Firebase, его нужно заполнить.
- `firestore.rules` — правила доступа к базе.
- `tests/simulate.js` — тест правил Golden Land.

Каждая игра лежит в одном HTML-файле. Сборка не нужна: GitHub Pages раздаёт файлы как есть.

## Подключение Firebase

Онлайн-комнаты заработают после того, как вы один раз заполните конфиг. Пока он пустой, Golden Land предлагает только игру на одном устройстве.

1. **Веб-приложение.** В Firebase console откройте проект PuzzleGekko → ⚙ Project settings → General → Your apps → значок `</>`. Укажите любой nickname, Hosting не включайте. Скопируйте объект `firebaseConfig`.
2. **Конфиг.** Вставьте значения в `shared/firebase-config.js` вместо `PASTE_…` и закоммитьте. Это не секрет: ключ веб-приложения публичный, доступ ограничивают правила из шага 5.
3. **Вход.** Build → Authentication → Get started → Sign-in method → **Anonymous** → Enable. Затем Authentication → Settings → Authorized domains → Add domain → `timofeevilia.github.io`.
4. **База.** Build → Firestore Database → Create database. Выберите **Standard edition**, location `asia-southeast1 (Singapore)`, режим **Production**. ID базы оставьте `(default)`.
5. **Правила.** Firestore → Rules: замените текст содержимым `firestore.rules` и нажмите Publish.
6. **Ключ (по желанию).** В Google Cloud Console → APIs & Services → Credentials откройте ключ «Browser key». В Application restrictions выберите Websites и добавьте `https://timofeevilia.github.io/*`.

Проверка: откройте `…/puzzlegekko/golden-land/` и нажмите **Create an online room**. Ссылку вида `…/golden-land/#K7QX` отправьте второму игроку.

### Толмач онлайн

Один игрок нажимает **Создать комнату** и отправляет ссылку. Каждый на своём телефоне выбирает роль: «Он · кириллица» или «သူမ · မြန်မာစာ».
- Читающий видит только свою фразу.
- Слушающий видит доску и делает ход.
- На этапе «Задача» предметы расставляют вместе: ставить их может любой из двух.

### Одна база на все игры

Все игры пишут в одну базу `(default)`, но каждая в свою коллекцию верхнего уровня:

```
golden-land/K7QX/game/current   ← партия в комнате K7QX
golden-land/K7QX/game/lobby
golden-land/K7QX/live/presence
tolmach/AB12/game/state        ← партия Толмача в комнате AB12
<следующая-игра>/<КОМНАТА>/...
```

У каждой коллекции свой блок в `firestore.rules`, поэтому игры не видят данные друг друга. Отдельную базу на каждую игру заводить не стоит: бесплатная квота Firestore даётся только базе `(default)`, а дополнительные базы требуют тарифа Blaze.

### Новая онлайн-игра

1. Подключите комнату: `const {openRoom} = await import("../shared/net.js")`, затем `openRoom("имя-игры", код)`.
2. Добавьте в `firestore.rules` блок `match /имя-игры/{room}/{section}/{doc}`.

## Golden Land

- **Поле.** 22 реальных места, по 11 в Таиланде и Мьянме, с названиями тайским и бирманским письмом.
- **Панель справа** (на телефоне она под полем) с вкладками:
  - **Build** — постройка хижин и курортов;
  - **Deals** — обмен и выкуп;
  - **Bank** — кредит и залог;
  - **Market** — SET, рубины и золото.
- **Домашние правила** включаются перед партией: копилка Water Festival, Language moments, выкуп, кредиты, рынок, растущие сезоны, мини-игры и классическое «дубль — ещё один ход».
- **Где ещё работает.** Та же страница работает как артефакт на claude.ai. Там вместо Firebase используется общая база самого артефакта.

## Sabai Thai

Курс тайского для носителей бирманского. Интерфейс на бирманском и английском.

**Разделы:**
- **Learn** — ежедневный урок с интервальным повторением. Типы карточек: новое слово, «вспомни», «послушай и выбери значение», «найди тайское слово», «скажи вслух». Есть цель на день, серия дней и слово дня.
- **Words** — словарь на 386 слов в 19 темах, включая «Электроника и SSD» и «Работа на заводе». У каждого слова тайское письмо, английская и бирманская транскрипция, тон каждого слога, перевод и озвучка. Поиск работает на любом из трёх языков.
- **Phrases** — 46 фраз для рынка, такси, кафе, работы, завода, врача и общения. Все фразы в женской форме вежливости (ค่ะ / คะ).
- **Sounds** — тоны с тренажёром, 42 согласные по классам, гласные, тайские цифры и тренажёр «услышь цену».
- **Progress** — статистика по темам, активность за 14 дней и настройки.

**Как устроено:**
- Озвучка — встроенный синтезатор речи браузера. Если на телефоне нет тайского голоса, страница подскажет, как его установить. Распознавание речи работает там, где браузер его поддерживает (Chrome, Safari).
- Бирманская транскрипция строится автоматически из слогов в `sabai-thai/data.js`. Это приближение: бирманские тоны не совпадают с тайскими, поэтому тайский тон показан отдельно.
- Прогресс хранится в Firestore: `sabai-thai-users/<uid>/data/progress` для входа через Google, `sabai-thai/<КОД>/data/progress` для входа по коду. Для включения нужны блоки Sabai Thai в `firestore.rules` и провайдер Google в Firebase Authentication.

## Gekko Party

Устроено как вечеринки в духе Jackbox: на большом экране открывают `…/party/` и выбирают версию. Игроки заходят с телефонов по адресу `…/party/` с четырёхбуквенным кодом или по QR-коду.

**Версии:**
- **Для двоих** — каждый выбирает язык, русский или бирманский. Телефон показывает всё на языке игрока, большой экран показывает оба.
- **English** и **Русский** — до 8 игроков.

**Игры:**
- **The Last Train / Последний поезд** — 8 вопросов в поезде с призраками. Кто ошибся, проходит одно из четырёх испытаний на телефоне:
  - шаткие сиденья;
  - арифметика на время;
  - запоминание фонарей;
  - стоп-кран.

  Проигравшие становятся призраками и играют дальше. В финале все бегут к локомотиву: нужно отмечать всё, что подходит к категории.
- **Doodle Lies / Каракули и враки** — каждый рисует на телефоне секретную тему двумя цветами. Потом остальные придумывают фальшивые названия и ищут настоящее. Вдвоём играется иначе: партнёр выбирает настоящее название из четырёх.
- **Ballpark / Примерно** — все пишут число, а потом ставят на ответ, который ближе всех к правде.
- **Quick Sketch / Быстрый карандаш** — один рисует абсурдную тему, штрихи вживую идут на большой экран. Остальные выбирают ответ из шести похожих вариантов на своём языке, и чем быстрее, тем больше очков. Художник получает половину очков угадавших.
- **Copycat / Копия копии** — рисунки перерисовывают по памяти, и каждая копия сложнее предыдущей:
  - уровень 1 — 6 секунд на запоминание;
  - уровень 2 — 3 секунды;
  - уровень 3 — рисование вслепую, линии не видны.

  Втроём и больше рисунки идут по кругу, а в конце по последней копии угадывают исходную тему. Вдвоём три раунда: оба рисуют новую тему, обмениваются и перерисовывают один раз (уровень = номер раунда), потом угадывают, что перерисовали.

**Темы для рисования** общие для трёх игр.
- **Состав.** Это сочетания «кто + что делает»: 69 героев × 60 ситуаций на трёх языках. Из этих сочетаний собран фиксированный банк в 1200 тем, в нём нет фраз из первой версии.
- **Ложные варианты.** Они похожи на правду: тот же герой в другой ситуации или та же ситуация с другим героем.
- **Без повторов.** Большой экран запоминает показанные темы (localStorage) и не повторяет их, пока банк не закончится.
- **Как добавить.** Новых героев и ситуации можно дописать в `party/content.js` (`WHO`, `WHAT`).

**Как устроено:**
- Партией управляет большой экран. Он один пишет `party/<КОД>/game/state`.
- Телефоны пишут только свои документы:
  - `players/<uid>` — профиль;
  - `input/<uid>` — ответ;
  - `input/<uid>_d<раунд>` — рисунок в виде штрихов;
  - `input/<uid>_r` — реакция-эмодзи.
- Это закреплено правилами в `firestore.rules`. После обновления файла правила нужно снова опубликовать в Firebase.

**Контент:** все вопросы, задания для рисования и вопросы-оценки лежат в `party/content.js` на трёх языках. Чтобы добавить свои, скопируйте строку и сохраните то же число частей через `|`.

**Графика и звук:**
- Персонажи и фоны нарисованы в SVG прямо в коде (`party/art.js`, зверьки в `party/common.js`).
- Анимации сделаны на CSS (`party/style.css`).
- Музыка и эффекты синтезируются через Web Audio (`party/sound.js`), поэтому файлов для загрузки нет.
- QR-код рисует `party/vendor/qrcode.js` (MIT).
- **Синхронизация телефонов:**
  - после разблокировки экрана или возврата в браузер телефон заново подписывается на состояние игры;
  - пока страница открыта, телефон сверяется с сервером раз в 5 секунд, на iPhone раз в 2,5;
  - на iPhone и iPad Firestore работает через long polling: WebKit иногда задерживает обновления в потоковом канале;
  - кнопка `КОД ↻` в шапке телефона обновляет экран вручную.

Горячая клавиша на большом экране: Shift+→ пропускает текущий этап.

## 81 Trials

Головоломки по роману «Путешествие на Запад» в стиле свитка и тушевой живописи. Персонажи и пейзажи нарисованы в SVG, музыка — синтезированные переборы в пентатонике.

**Устройство:**
- Главный экран — свиток на 81 испытание.
- Каждое испытание состоит из диалога с героями, правил, головоломки, до трёх подсказок и итоговых печатей:
  - 过 — испытание пройдено;
  - 巧 — без ошибок и лишних ходов;
  - 明 — без подсказок.
- Прогресс хранится в браузере (localStorage).

**Открытые испытания:**
1. **Гора Пяти Стихий:** поворот фрагментов талисмана, чтобы они сложились в одну сеть (головоломка Net).
2. **Плоды женьшеня:** найти подделку взвешиваниями (9 плодов за 2 взвешивания, 12 плодов за 3). Дух сада подменяет подделку так, чтобы угадать было нельзя.
3. **Белая Кость:** демоны лгут, люди говорят правду. Задачи генерируются заново с проверкой, что решение единственное.
4. **Река Тунтянь:** переправа трёх монахов и трёх демонов.
5. **Огненная гора:** веер переключает клетку и её соседей (головоломка Lights Out).
6. **Пещера Паутин:** распутать граф так, чтобы нити не пересекались.

**Код:**
- `journey/trials.js` — испытания;
- `journey/art.js` — герои, печати, пейзажи;
- `journey/game.js` — свиток, диалоги, результаты.

Новое испытание добавляется объектом в массив `TRIALS`.

## Equilibrium

Игра для одного игрока: вы и пятеро ИИ-соперников. У каждого соперника скрытый характер, всего характеров семь, за столом пять из них:
- Зеркало;
- Злопамятный;
- Лис;
- Святой;
- Акула;
- Аналитик;
- Маятник.

**Раунды.** Их восемь, в каждом новая игра из теории игр. Партия берёт восемь из одиннадцати карт, дилемма заключённого в колоде дважды. Карты:
- дилемма заключённого;
- «лобовая»;
- ультиматум;
- охота на оленя;
- общий котёл;
- доброволец;
- меньшинство;
- «две трети среднего»;
- аукцион, где платят все;
- налог на лидера.

**Переговоры перед выбором.** Два действия на выбор:
- публичное обещание;
- сделка: устная, с неустойкой или с доплатой;
- шпион;
- подарок.

При вскрытии все обещания проверяются публично, и по этой истории можно вычислить характеры (догадки отмечаются в таблице игроков).

**Выбывание и финал.** После 2, 4, 6 и 8 раундов игроки голосуют, и один выбывает. Голос одного соперника можно попробовать перетянуть. Двое оставшихся играют «Поделить или украсть».

Код — `equilibrium/game.js`. Прогресс партии хранится в браузере. Firebase не используется.

## Merit Academy (архив)

Игра для одного игрока, сделана по мотивам особых экзаменов из «Добро пожаловать в класс превосходства». Школа, персонажи и правила свои.

Вы — ученик класса D, последнего в рейтинге. У классов есть **очки класса**, у вас — **личные очки** (стипендия, магазин, балл защиты от исключения), у одноклассников — **доверие** к вам.

**Кампания** — четыре экзамена, между ними свободное время: учёба, тренировки, вечера с одноклассниками, информатор.
1. **Необитаемый остров.** Бюджет 300 очков на 7 дней и тайный лидер. Лидер занимает точки, разведчики собирают улики о чужих лидерах, ночью случаются события (шпионка из C, шторм, кража). На 7-й день можно назвать чужих лидеров. Лазейка: лидер «заболевает» и передаёт роль другому.
2. **Цель.** Группа из восьми, по двое из каждого класса, и одна тайная Цель. У каждого карточка с фактом, у Цели карточка ложная, ИИ-ученики иногда врут. В досье можно отмечать, каким фактам вы верите. В любой момент можно предать группу. Иногда Целью оказываетесь вы.
3. **Единогласие.** Пять вопросов, класс должен проголосовать единогласно. Убеждать можно логикой, эмпатией, деньгами или давлением, и на каждого действует своё. Последний вопрос — исключить одного ради 100 очков, и исключить могут вас.
4. **Дуэль классов.** Выбор дисциплин и состава. В трёх дисциплинах командир играет сам: взлом кода, викторина (вопросы из `party/content.js`), камень-ножницы-бумага против привычек вражеского лидера.

**Экзаменационный зал** — любой экзамен отдельно.

**Как устроено:**
- Прогресс кампании хранится в браузере (localStorage).
- Код: `merit/game.js` (кампания), `merit/exam-*.js` (экзамены), `merit/people.js` (персонажи и SVG-портреты).

## Проверка

```
node tests/simulate.js
```

Скрипт прогоняет 200 случайных партий Golden Land со случайным набором домашних правил. Он падает, если игра застревает, деньги или цены становятся некорректными, или срабатывает выключенное правило.
